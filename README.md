# wiki-agent

本地优先的知识库编辑器。桌面端（macOS、Windows）和网页版是同一套功能。没登录时页面写在本机，登录后再同步。

网页版：<https://wiki.championsea.online>

---

## 功能

### 块编辑

标题、列表、待办、引用、代码、表格、图片和子页面都是块，拖动手柄调整顺序。代码块不限高度，并按语言高亮；拖动手柄停在卡片左上角。

### 页面树

侧栏分成个人文章和团队。有收藏，或发出过分享，对应分区才出现；没有就不占位置。可以搜索，也可以把页面拖到别的层级。正文里的子页面是页面链接，点进去才打开那一页。

### 待办与通知

待办可以设起止日期，完成后划线，也能切到甘特图。通知在侧栏右下角，点用户名打开设置。

### AI 助手

选中文字后提问，回答可以直接插入正文。也可以打开知识库，对着已有页面连续对话。

### 导入与导出

Word 和 Excel 可以覆盖当前页、插到开头，或接在末尾。Markdown 会转成新页面。页面可以导出 PDF 和 Word。

### 分享与收藏

分享出去的是只读页，有效期可选 1 天、7 天或 30 天。对方用浏览器打开，不需要安装客户端。登录后可以收藏别人分享的文章，自己的文章不能收藏。没有收藏时，侧栏不显示收藏栏。分享页顶栏和登录、收藏同一行，可以下载最新版。

### 同步与团队

未登录只写本机。登录后在设备之间同步。团队页面按角色一起编辑，使用者只能查看。

下一版要做的团队详情、邀请链接、成员列表和移动端侧边栏菜单，记在 [docs/next-iteration.md](docs/next-iteration.md)。先不开发。

## 本地开发

需要 Node ≥ 20、pnpm 9.12.2。

```bash
pnpm install
pnpm dev:editor
```

编辑器开发地址：<http://127.0.0.1:5174>。桌面端开发用 `pnpm desktop`。

发版：

```bash
pnpm ed release x.y.z   # 改版本号、打 tag、推送，触发桌面安装包打包
pnpm ed ship            # 安装包传到 OSS，并部署网页
```

`pnpm ed` 还可以查看状态、只部署网页、列出 OSS 上的版本。业务接口在 NestJS 的 wiki 服务，编辑器只请求 `/wiki/*`。

## 仓库

| 路径 | 作用 |
|------|------|
| `apps/editor` | wiki-agent：网页、桌面端、下载页 |
| `packages/shared` | 编辑器与博客共用的文档类型 |
| `apps/web`、`apps/server` | 原来的博客前台和 API |

博客仍用 `pnpm dev` 启动，前台 <http://localhost:5173>，工作区在 `/admin`。
